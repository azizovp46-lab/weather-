AeroWeather — готовое PWA-приложение для Android

1. Создай на GitHub новый публичный репозиторий, например aeroweather.
2. Загрузи в корень репозитория ВСЕ файлы и папку icons из этого архива (не сам ZIP целиком).
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. Открой получившуюся HTTPS-ссылку в Chrome на Android.
5. Меню ⋮ → Установить приложение / Добавить на главный экран.

Приложение будет запускаться без адресной строки. Живой фон и интерфейс доступны офлайн, а новые прогнозы, новости и карта требуют интернет.
На частном file:// адресе или внутри некоторых браузеров пункт «Установить приложение» может не появляться.
